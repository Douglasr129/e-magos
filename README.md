# 🛒 Geek E-Commerce

Plataforma de e-commerce voltada para produtos da cultura geek (colecionáveis, HQs, games, tecnologia e muito mais).  
Desenvolvida em **.NET 10** com arquitetura modular, suporte a **versionamento de APIs** e documentação via **Swagger**.

---

## 🚀 Tecnologias utilizadas

- [.NET 8](https://dotnet.microsoft.com/)
- [ASP.NET Core Web API](https://learn.microsoft.com/aspnet/core)
- [Entity Framework Core](https://learn.microsoft.com/ef/core) (ORM)
- [Asp.Versioning](https://github.com/dotnet/aspnet-api-versioning) (versionamento de APIs)
- [Swashbuckle.AspNetCore](https://github.com/domaindrivendev/Swashbuckle.AspNetCore) (Swagger/OpenAPI)
- [PostgreSQL] (banco de dados, conforme configuração)
- [JWT Authentication](https://jwt.io/) (autenticação e segurança)
